# Laravel CRUD Application

This project is a **CRUD (Create, Read, Update, Delete)** application built using **Laravel**, designed to demonstrate how to manage data efficiently through a web interface. The application performs basic database operations such as adding, viewing, editing, and deleting records.

---

## 🚀 Features
- **Create:** Add new records through a simple form.
- **Read:** Display all stored records in a dynamic table.
- **Update:** Edit existing records easily with form validation.
- **Delete:** Remove unwanted records securely.
- **Validation:** Input validation on both frontend and backend.
- **Responsive UI:** Clean and user-friendly interface.

---

## 🛠️ Technologies Used
- **Framework:** Laravel
- **Frontend:** Blade Templates, HTML, CSS, Bootstrap
- **Database:** MySQL
- **Server:** PHP (with Artisan for local development)
